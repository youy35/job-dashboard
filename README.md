# 尤悦 · 机会工作台

国内求职与全球国际机会的个人工作台：[打开网页](https://youy35.github.io/job-dashboard/)。

## 每天怎么用

1. **今天**：只看自己关注的机会、正在准备的申请和手动安排的任务。新搜索结果不会自动进入待办，也不会计入“正在申请”。
2. **发现机会**：按专业招聘、跨专业工作、奖学金与交流、志愿者、国内国际项目浏览。每页12条；支持搜索、地点和渠道筛选。
3. 感兴趣就点 **关注**。不感兴趣点“暂不考虑”，以后可恢复。指南、回顾、录用消息和远程志愿按标题初筛至“资讯 / 远程志愿”；自动分类可能有误，可查看全部。
4. **查看详情**：已知事实与“申请前还需确认”集中展示。点击原始来源，核实个人资格、截止日期、签证、资助和真实自费，再设置准备、投递或面试进度。关注不是“资格已符合”。
5. **我的申请**：维护自己的清单。需要评估、写申请信、准备材料或跟进联系人时，展开“申请工具”中的相应工具。
6. **设置与备份**：更新机会、导入旧文件、导出完整备份。旧岗位、申请进度、备注、任务和联系人继续使用；完整备份还包含关注及收起记录。首次使用新版不会擅自把旧线索当作关注。

所有个人记录保存在当前浏览器，换设备、清理缓存前请备份。新版继续使用原有岗位与附加记录存储键。

## 筛选偏好

保留考古、历史、博物馆、高校行政、博士后和文化遗产方向，增加跨专业工作、带资助志愿者、奖学金、交流培训及从国内可申请的国际项目。搜索方向不代表本人符合条件或专业不限。

总自费优先3000–8000元，其次8000–15000元，低于3000元同样优先，不设硬上限；比较时长、可迁移技能和未来海外发展价值。费用应合计项目费、机票、签证、食宿、保险、当地交通和报销前垫付。费用未知不视为免费。

## 信息来自哪里

保留21组 Google News RSS 新闻检索，另外在 `scripts/sources.json` 配置36个定向渠道：

- 国内：广东、广州、北京、江苏、上海、重庆、浙江、四川人社渠道；中山、复旦、北大、浙大、南大及科学院/社科院相关官网；高校人才网、留学基金委。
- 公众号：考古博物馆、高校招聘、国际资助交流3组公开文章索引，并提供搜狗微信手动搜索入口。
- 海外：EURAXESS、jobs.ac.uk、HigherEdJobs、JREC-IN、UNESCO、UNDP、UNV、联合国招聘、Erasmus+、DAAD、ReliefWeb、Impactpool，以及剑桥、港大、NUS、ANU招聘入口。

**配置渠道不等于已完整采集。** 官网读取公开静态列表；不能加载的动态岗位、登录与验证码页面不绕过。公众号仅尝试公开搜索索引，搜索服务可能忽略站点限制；结果必须通过域名检查才能入库，否则标“覆盖未确认”。本次测试未得到有效公众号文章，不代表公众号没有相关招聘。

“发现机会”下方展开 **渠道目录与采集情况**，可查看每个渠道的方式、发现数量、零匹配、覆盖未确认或暂不可用状态，并手动打开来源。尚未覆盖全国所有学校和省市，也不会自动读取用户微信订阅或历史消息。

官网、公众号和聚合平台分别标注。**官方来源只说明发布渠道；不代表岗位仍开放、本人符合资格或资助已核实。** 自动结果均保持 `verification_status: lead`。不会根据标题猜年龄、国籍、签证、金额或截止日期，也不会展示虚构的匹配概率。

## 自动更新与手动运行

GitHub Actions 每天北京时间09:00尝试更新，可能延迟。网页默认打开时读取最新结果，可在设置关闭。GitHub → Actions → Daily Job Radar → Run workflow 可手动运行。它与 ChatGPT 定时任务分别运作。

单渠道失败会记录并保留历史；全部请求失败则停止且不改数据。解析会过滤栏目首页、录用公示、成绩/体检名单及明显无关项，但仍需人工判断专业限制、公告时效及重复转载。

## 数据兼容与开发

`jobs-feed.json` 保留顶层 `generated_at`、`jobs` 和原有岗位字段。新增字段均为可选：`source_kind`（official/wechat/aggregator）、`source_id`、`discovery_method`、`official_url`、资格及费用待核实项；顶层 `sources`、`search_report`、`cost_policy` 提供渠道配置、实测结果和预算偏好。旧版 JSON 仍可导入。

`published_at` 只存来源明确提供的发布时间；索引返回时间另存 `indexed_at`，不能当成公告发布时间。按链接去重、保留已有事实和记录；新发现排前，公开 feed 最多500条，历史超限尾部移出公开 feed，不删除浏览器已导入记录。

Python 3.11+，采集无需第三方库。页面为独立 HTML，无需构建。

```sh
python -m unittest discover -p 'test_*.py' -v
node test_dashboard.cjs
python scripts/update_jobs.py
# 分别测试来源，并输出到独立文件
python scripts/update_jobs.py --channels-only --output /tmp/channel-test.json
python scripts/update_jobs.py --news-only --output /tmp/news-test.json
```

新增来源可编辑 `scripts/sources.json`，须设置准确域名、栏目地址、来源类型和采集方式，并测试；海外列表建议配置只匹配岗位详情的 `entry_pattern`。不要将首页、搜索筛选器或索引抓取时间伪装成真实岗位信息。
