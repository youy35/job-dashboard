# 全球工作与低成本国际机会雷达

保留考古、博物馆、高校行政、博士后和文化遗产招聘，新增全球跨专业工作（含国际教育、公益、动物福利、运营与带薪实习）、资助志愿者、奖学金/交流/培训，以及从国内申请的国际项目。

**搜索方向不代表专业不限、本人符合条件、项目正在开放或已确认获得资助。** 当前数据来自 Google News RSS 标题筛选，只是搜索线索；不会自动打开并核实官方公告，可能含过期、无关、限定国籍或需单位推荐的结果。国内国际项目也必须核实是否允许个人申请。没有结果不代表没有机会。

## 如何使用（无需改代码）

1. 打开工作台，在“全球机会线索同步中心”点击“从网站读取最新线索”。也可勾选每次打开尝试同步。
2. 在“所有方向”里选择新增分类；展开“资格、资助与费用”查看待核实项。地点未知单列，不默认当作海外。
3. 点击“来源 / 公告”，找到主办方当期官方页面。新闻链接可能跳转，不能当作申请入口。
4. 用“编辑”记录国籍/居住地、年龄、语言、专业/学位及毕业时间、个人申请/单位推荐、截止日期、签证/工作许可、资助期限、补贴、食宿、交通、保险、总自费与垫付条件。
5. 结合时长、技能、人脉和未来海外就业价值判断，再改为“准备申请”。填写“最后核验日期”和官方公告链接，并在备注写证据。申请进度不等于事实已经核实。
6. 浏览器数据只保存在本机，请定期“导出完整工作台备份”。同步只新增和去重，不覆盖你已有的备注、评分、联系人和申请进度；已导入记录不会自动刷新，应手动复核。

预算偏好：低于3000元同样优先；优先自费3000–8000元，其次8000–15000元，不设硬上限。必须合计项目费、机票、签证、食宿、保险、当地交通及报销前垫付。费用未知不视为免费，标题中的“fully funded”也不视为已确认。警惕高额中介费和商业游学。

## 自动更新与手动更新

GitHub → 本仓库 → **Actions** → **Daily Job Radar** → **Run workflow** → 运行。看到绿色勾后回到网页点击同步。原有任务每天北京时间09:00尝试运行，GitHub 可能延迟；并非 ChatGPT 的定时任务。

脚本的21组搜索请求最近90天新闻；该范围是搜索条件，不保证公告仍有效。单项失败会保留历史记录，并在 `search_report` 记录；全部失败时任务报错且不改原数据。成功但零结果同样记录。新闻标题仅做基础相关性筛选，不自动提取资格、金额、日期或认定签证支持。

## 数据兼容与维护

`jobs-feed.json` 继续使用顶层 `generated_at` 和 `jobs` 数组；旧字段 `org/role/country/city/track/url/source/notes` 保留。新增可选字段：

- `verification_status: "lead"`、`status: "待核实"`：自动结果固定未核实，不生成已核实岗位。
- `official_url`、`verified`、`deadline`：未知为空，不能从检索日期推断截止日期。
- `nationality/age/language/eligibility/visa/funding/costs/duration/development_value`：默认待核实/待评估。
- `estimated_self_cost_cny: null`：不猜费用；`published_at` 仅记录 RSS 原始新闻日期。
- `opportunity_type`、`search_query`：发现方向与检索词，不是已核实的项目分类。
- 顶层 `cost_policy` 与 `search_report`：预算偏好及每项搜索的成功、数量或失败原因。

按链接去重，保留已有字段及人工核实记录；新发现排前，最多500条（历史超限尾部会移出公开 feed，本地已导入记录不受影响）。不同链接转载仍可能重复，需人工判断。损坏的旧 JSON 会报错停止，避免静默丢失记录。页面仍接受旧版 JSON，新字段缺失时显示待核实。

开发者本地运行（Python 3.11+，无额外依赖）：

```sh
python -m unittest -v test_update_jobs.py
python scripts/update_jobs.py
# 用单独文件测试联网，避免改动正式 feed：
python scripts/update_jobs.py --output /tmp/jobs-test.json
```

`index.html` 是原有工作台的扩展；存储键保持不变。公开 feed 不应写入申请材料、私人联系方式等信息。各项申请资格与费用以官方当期公告为准。
